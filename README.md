# 晚栀 Playroom

一个可扩展的轻量在线游戏平台。首版包含游戏大厅、五子棋本地双人、人机对战和房间码好友对战。大厅中的游戏入口按分类组织，后续可以在 `public/index.html` 添加游戏条目，再将各游戏逻辑拆进独立模块。

## 本地运行

需要 Node.js 18 或更高版本。

```sh
npm install
npm start
```

默认监听 `3007` 端口，浏览器打开 `http://localhost:3007`。也可通过环境变量 `PORT` 覆盖端口。好友对战要求两台设备都能访问运行服务的地址。

## 宝塔部署：直接使用 IP 和端口

当前没有域名时，不需要配置宝塔网站或 Nginx 反向代理，Node 服务会直接提供网页和 WebSocket。

1. 在宝塔安装 Node.js 18 或更高版本，并上传项目中的 `package.json`、`server.js` 和 `public` 目录。
2. 在宝塔终端进入项目目录，执行 `npm install`。
3. 在 Node.js 项目管理器中添加项目，项目目录选择上传目录，启动文件选择 `server.js`，端口设为 `3007`，并用 PM2 守护运行。若管理器要求填写启动命令，可用 `npm start`。
4. 在云服务器厂商的安全组和宝塔防火墙中放行入站 TCP `3007` 端口。
5. 访问 `http://服务器公网IP:3007`。好友也使用同一个 IP 和端口打开页面；好友对战的 WebSocket 会自动连接到同一地址的 `/ws` 路径。

若服务器启用了系统防火墙，也需要放行 TCP `3007`。公网 IP 需要是可从互联网访问的地址；内网 IP 只能供同一局域网访问。

## 后续绑定域名

以后绑定域名并启用 HTTPS 时，可以让 Nginx 把网页和 WebSocket 反向代理到 `127.0.0.1:3007`。HTTPS 域名下浏览器会自动使用安全 WebSocket。

## 当前限制

房间和棋局保存在服务内存中，服务重启会清除未完成房间。当前版本没有账号、观战、断线恢复和持久化战绩。公开部署前建议增加房间创建频率限制及连接校验；若需要跨进程扩容，再将房间状态迁移到 Redis。
